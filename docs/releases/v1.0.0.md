# NetDoctor v1.0.0

**Status: Release candidate — pending final Windows installation and acceptance testing.**

NetDoctor is a free, open-source Windows application that helps users investigate internet connectivity problems through evidence-based diagnostics, practical explanations, and guided troubleshooting.

This release brings together NetDoctor's existing diagnostic tools under a unified interface designed around the networking problems people actually encounter.

---

## What's New

### 1. Guided Network Troubleshooting

NetDoctor now provides seven guided troubleshooting questions:

1. **What's wrong with my internet?**
2. **Why is my port forwarding not working?**
3. **Why is my internet slow?**
4. **Why does my internet keep disconnecting?**
5. **Why won't a website open?**
6. **Which VPS location has the lowest latency?**
7. **Is my VPN working?**

Each question guides users through relevant checks and presents understandable findings and recommended next steps.

Diagnostic conclusions distinguish observations from possible explanations and unresolved causes.

### 2. Internet Fault Isolation

The main internet diagnosis combines available information from:

- Windows network adapters
- Default routes and gateways
- Gateway responsiveness observations
- DNS queries
- Public HTTPS connectivity checks

Users can optionally provide comparisons involving another device on the same network or the same PC using a different connection.

These comparisons can help narrow the likely problem area.

**NetDoctor does not claim that a single diagnostic snapshot can conclusively distinguish every PC, router, or ISP fault.**

### 3. Improved Port Forwarding and CGNAT Guidance

NetDoctor provides practical guidance for common inbound connectivity problems.

It recognizes private IPv4 addresses and carrier-shared address space, explains potential upstream NAT limitations, and suggests appropriate next steps.

Depending on the available information, these may include:

- Checking an upstream router
- Contacting the ISP about public IPv4 availability
- Using Tailscale or ZeroTier for private connectivity between authorized devices
- Investigating compatible public tunnels or relay services

NetDoctor does not automatically configure router settings or verify that a specific inbound port is open.

### 4. Unified Application Navigation

The application now provides a unified sidebar with:

- Ask NetDoctor
- Explore Tools
- Overview
- Diagnosis
- Activities
- Stability
- Cloud Regions
- Network Details

The navigation remains accessible while the main content area scrolls independently.

### 5. Redesigned Permission Dialogs

Browser-native confirmation windows have been replaced with NetDoctor-styled in-page dialogs.

External network operations require explicit user approval.

Canceling a confirmation prevents the associated test from starting.

### 6. VPN Exit-IP Comparison

NetDoctor can compare externally observed public-IP information before and after a user connects a VPN.

Results may indicate whether:

- The public IP address changed
- The reported IP-based country changed
- A different exit network was observed

This feature is not a comprehensive VPN security or leak test.

## Privacy and Security

NetDoctor is designed to operate locally without requiring an account or subscription.

- Diagnostic history is stored locally.
- External network checks require user initiation and consent.
- External services may observe the public IP used for a request.
- No AWS or Oracle cloud account is required.
- NetDoctor does not automatically change Windows network settings, firewall rules, DNS configuration, or router settings.
- No paid cloud resources are created.

Some local diagnostic data and logs may remain after uninstalling the application.

---

## Known Limitations

NetDoctor is a diagnostic aid, not a replacement for professional network analysis or ISP support.

Important limitations include:

- A single PC cannot definitively identify every router or ISP fault.
- Short measurements may miss intermittent problems.
- Failed ICMP probes do not necessarily mean a router or destination is unavailable.
- Direct DNS tests may behave differently from Windows or browser name resolution.
- Successful TCP connections do not prove usable internet throughput.
- Cloud-region endpoint timings are not actual VPS benchmarks.
- VPN exit-IP comparisons do not establish encryption strength or complete leak protection.
- Private WAN addressing alone does not prove ISP-side CGNAT.
- External service availability and network policies may affect results.

NetDoctor is designed to state uncertainty when available measurements do not establish a reliable conclusion.

## Windows Installation

**Installer:** `NetDoctor-Setup-v1.0.0-x64.exe`

**Checksum:** `NetDoctor-Setup-v1.0.0-x64.exe.sha256`

### Requirements

- 64-bit Windows 10 or Windows 11
- Microsoft Edge WebView2 Runtime
- Internet connectivity for external diagnostic features

The installer bundles the application and its Python runtime.

Users do not need to install Python or Node.js.

### Security Notice

The installer is currently unsigned.

Windows may display an unrecognized-publisher or reputation warning.

Only download NetDoctor from the official GitHub repository:

https://github.com/QuantumCruz/NetDoctor/releases

Do not disable Windows security protections to install the application.
